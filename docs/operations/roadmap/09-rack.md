# ラックの導入と 3D プリントのマウント

[ロードマップ](README.md)の大型計画。10 インチラックを買い、ThinkCentre M70q（Proxmox）、ER605、SG2210P を載せる。機器を固定するマウントは 3D プリントで作る。自宅に 3D プリンターは無いので、印刷は業者に頼むか、Etsy で印刷済みの品を買う。ケーブルの整理にはパッチパネルを使う。ラックは候補を選んだ段階で、未購入・未着手。

詳細は `hardware/rack-10inch/` にある。この文書は、進行の順序とチェック項目だけを持つ。

## 目的

- 3 台（M70q、ER605、SG2210P）を 10 インチラックにまとめ、配線と置き場所を整える
- 引っ越しや模様替えのとき、持ち運びしやすい形にする（[VLAN 設計](../../architecture/08-vlan-design.md)の「物理設置」の未決事項）
- 後から足す機器（OPNsense 用 PC、通信の受信用ホスト、NAS、UPS）の置き場所を確保する

## 前提

- 自宅に 3D プリンターは無い。印刷は業者に頼むか、Etsy で印刷済みの品を買う
- ER605 と SG2210P は未購入。購入は [Omada 導入・VLAN 化](04-network-omada-vlan.md)の段階 1〜2 で行う。ラックの導入は、これらの購入を待たずに、M70q から始められる
- M70q は Proxmox ホストとして稼働中。ラックに移すには、全 VM の停止を伴う

## 基本方針

- **M70q から始める。** M70q の実機は手元にあり、確認の報告もある。ER605 と SG2210P のマウントは、機器を買ってから、実機で合うか確かめた上で頼む（SG2210P のモデルは、実機で合った報告が見つかっていない）
- **最初は 1 点だけ頼む。** 3 点を一度に頼まず、最初に安い素材で M70q 用だけ頼み、実機で合うかを確かめる。送料は増えるが、失敗したときの損を小さくする
- **素材は PLA を避ける。** 作者の推奨は PETG、ABS、ASA。業者が PETG を扱わないときは、ABS を選ぶ
- 他人のモデルは、ライセンスを守って使う。リポジトリに置いたデータの出所は `models/*/SOURCE.md` に書く。BY-NC のデータは、営利目的に使わない
- **印刷済みの品を買う案（Etsy）も比べる。** 印刷業者に頼むより、Etsy で印刷済みのマウントを買う方が安そうだ（メモの段階で、価格は未確認）。出品は機種ごとに違うので、M70q、ER605、SG2210P に合う品があるか、素材（PETG・ABS が望ましい。PLA は避ける）、送料、関税・消費税を調べて、業者の見積もりと総額で比べる
- **配線はパッチパネルで整理する。** 機器の背面からパッチパネルまでを短いケーブルでつなぎ、壁やほかの機器へはパネルの前面から出す。ケーブルの抜き差しや交換が、機器の背面に触れずにできる
- ラックの規格は 10 インチ・1U 単位。機器の置き換えで形が変わっても、同じラックに収められるようにする

## 導入の段階

### Phase 1: 方式の決定とラックの購入

- [ ] ラックの機種を決める。候補は DeskPi RackMate T1（8U、税込 21,999 円）。4U の T0 とも比べる（[候補と相性](../../../hardware/rack-10inch/README.md#ラックの候補)）
- [ ] ラックのネジの規格（M5 か #10-32）と付属品を確認する。足りないネジは別に買う
- [ ] 電源の置き場所を決める（M70q、ER605、SG2210P は AC アダプター。ラックに電源タップ用の棚は無い）
- [ ] ラックを購入する

### Phase 2: M70q 用マウントの印刷

- [ ] STL をスライサーで開き、左側のキーストーン口が M70q の LAN ポートの側にあるか確かめる（`left` と `right` が逆なら、`right_Keystone` に変える）
- [ ] Etsy に M70q 用の印刷済みマウントの出品があるか調べ、業者の見積もりと総額で比べる（素材、送料、関税・消費税、届くまでの日数、ライセンス）。安ければ、業者より先にこちらを選ぶ
- [ ] 印刷業者を決める。第一候補は JLC3DP の FDM（ABS）。国内で確実に欲しいときは DMM.make の MJF（PA12）。見積もりを取り、送料と関税・消費税を足した総額で比べる
- [ ] 注文する（M70q 用だけ）
- [ ] 届いたら、M70q が入るか、ラックに留められるか、キーストーンが付くか確かめる
- [ ] 合わなければ、原因（穴位置、奥行き、公差）を記録し、必要なら STL を直して別名で置く

### Phase 3: ER605 と SG2210P 用マウントの印刷

- [ ] ER605 と SG2210P を購入する（[Omada 導入・VLAN 化](04-network-omada-vlan.md)の段階 1〜2）
- [ ] SG2210P の版数を確認する（Omada に対応する版か）
- [ ] 機器の寸法を測り、モデルと合うか確認する
- [ ] 注文する。Phase 2 の結果（素材、業者、公差）を反映する

### Phase 4: M70q のラックへの移設

- [ ] バックアップを確認する（[バックアップと復旧](../runbooks/06-backup-restore.md)）
- [ ] 作業の日を決める。**全 VM が止まり、家の DNS（`vm-infra`）も止まる**。作業中の名前解決をどうするかを決める
- [ ] PVE ホストの 9.2 更新（[未着手の項目](01-backlog.md)）も、全 VM の停止を伴う。同じ日にまとめられるか検討する
- [ ] VM を順序どおりに停止し（[VM 自動起動・停止](../runbooks/01-vm-startup-shutdown.md)）、M70q をラックに移す
- [ ] 起動し、全 VM とサービスが復旧したことを確認する（IP は変えない）

### Phase 5: 配線の整理と記録

- [ ] パッチパネルを決める（10 インチ・0.5U か 1U、ポート数、キーストーン式か一体型か、Cat6 対応）。ポート数は、今の機器と後から足す機器（OPNsense 用 PC、NAS など）を見込んで選ぶ
- [ ] パッチパネルを取り付け、機器 ⇔ パネル、パネル ⇔ 壁・ほかの機器のケーブルを分ける。どのポートがどこにつながるか、ラベルと一覧を残す
- [ ] ケーブルの長さと取り回しを整える（M70q の背面の LAN からキーストーンまで、約 30 cm）
- [ ] 通気を確認する（ラックの後ろに 10 cm 程度の空間、M70q の発熱）
- [ ] 設計書・構成図を更新する（物理設置の未決事項を決定に変える。必要なら ADR に残す）
- [ ] 使った業者、素材、金額、合わなかった点を `hardware/rack-10inch/` に記録する
- [ ] 完了したら [02-completed.md](02-completed.md) に一行残し、01 の項目を消す

## 費用の目安

ここは概算で、実際の見積もりで確認する。

| 項目 | 目安 | 備考 |
| --- | --- | --- |
| ラック（RackMate T1、8U） | 21,999 円 | 税込、Amazon.co.jp、2026-11-01 時点。中古は 17,764 円の出品があった |
| 3D プリント（JLC3DP、FDM の ABS） | 数千円 + 送料 + 関税・消費税 | 3 点の体積は約 461 cm³（中実で約 480 g）。FDM は $0.07/g から（比較記事の記載）。送料は約 1,000〜3,000 円（同） |
| 3D プリント（Etsy の印刷済み品） | 未確認 | 業者に頼むより安そうだ、というメモ。出品の価格・送料・関税・消費税を調べて、業者の見積もりと比べる |
| 3D プリント（DMM.make、MJF の PA12） | 約 5 万円 | 素材費のみで 113 円/cm³ × 約 461 cm³。国内で確実だが、割高 |
| キーストーン、LAN ケーブル、ネジ | 数百〜数千円 | 未確認 |
| パッチパネル、棚、電源 | 必要に応じて | パッチパネル（0.5U、12 ポート）は 2,999 円の出品があった |
