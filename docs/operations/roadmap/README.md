## 運用

- 小さな項目は 01 に書く。複数の段階にわたる大型計画は、04 以降の番号付きの文書として分ける
- 検討して見送った項目は、理由と再検討する条件を 03 に残す
- 検討中の案は、ここに書く（設計書・ADR には、採用するまで書かない）。採用したら、詳細を設計書・ADR に移す。手順は [文書の運用](../../README.md#文書の運用)
- 着手した項目は、詳細を設計書・ADR に移し、02 に一行で残す
- 新しい文書を追加するときは、04 以降の次の番号を振り、この表と `docs/README.md` を更新する
