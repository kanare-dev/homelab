# roadmap

このホームラボの今後の拡張計画。現行構成は `README.md` と `docs/architecture/` に書き、ここでは「これからやること」「見送ったこと」「終わったこと」を整理する。現行構成は、メモリを `24GB` に増設済みのホストを前提とする。

## 文書

| 番号 | 文書 | 内容 |
| --- | --- | --- |
| 01 | [未着手の項目](01-backlog.md) | 領域ごとの未着手の項目 |
| 02 | [完了済みの項目](02-completed.md) | 完了した項目の一覧。詳細は設計書・ADR へのリンク |
| 03 | [見送り中の項目](03-deferred.md) | 見送った理由と、再検討する条件 |
| 04 | [Omada 導入・VLAN 化](04-network-omada-vlan.md) | 大型計画。ER605・SG2210P・AP、VLAN の段階とチェック項目 |
| 05 | [GPU 搭載ゲーミング PC 兼ホームサーバー](05-gpu-pc.md) | 大型計画。目的、構成、Phase 1〜6 |
| 06 | [ネットワーク通信の収集・可視化](06-network-traffic-analysis.md) | 大型計画。要件、Wi-Fi 端末の取得位置、Phase 1〜4 |
| 07 | [DMZ と外部公開](07-dmz.md) | 大型計画。DMZ の VLAN、ハニーポット（Cowrie）、公開用 Web サーバー、外部公開の経路、Phase 1〜5 |
| 08 | [OPNsense 導入](08-network-opnsense.md) | 大型計画。補助的な役割での検証から ER605 の後継へ。購入基準、Phase 1〜3 |
| 09 | [ラックの導入と 3D プリントのマウント](09-rack.md) | 大型計画。10 インチラックに M70q・ER605・SG2210P を載せる。マウントの 3D プリント（業者に依頼）、移設、Phase 1〜5 |

## 運用

- 小さな項目は 01 に書く。複数の段階にわたる大型計画は、04 以降の番号付きの文書として分ける
- 検討して見送った項目は、理由と再検討する条件を 03 に残す
- 着手した項目は、詳細を設計書・ADR に移し、02 に一行で残す
- 新しい文書を追加するときは、04 以降の次の番号を振り、この表と `docs/README.md` を更新する
