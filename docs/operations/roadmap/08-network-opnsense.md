# OPNsense 導入

[ロードマップ](README.md)の大型計画。OPNsense 用の機器（N100 など）が買いやすくなったら、まず補助的な役割で設定・検証し、実績を確認したうえで ER605 の後継（家の入口のルーター）にする。機器は未購入で未着手。

詳細は設計書と ADR にある。この文書は、進行の順序とチェック項目だけを持つ。

| 内容 | 参照先 |
| --- | --- |
| ルーターは ER605 を先に、OPNsense は後にする判断 | [ADR 0009](../../adr/0009-router-er605-first.md) |
| VLAN・アドレスの設計（OPNsense の扱いは「未決事項」） | [VLAN 設計](../../architecture/08-vlan-design.md) |

## 目的

- OPNsense（N100）で、ファイアウォールなどネットワーク技術を学ぶ
- 検証を重ねたあと、ER605 を OPNsense に置き換える

## 前提

- [Omada 導入・VLAN 化](04-network-omada-vlan.md)の段階 3（VLAN への一斉切り替え）まで終えている。ER605 + Omada で当面運用する
- 機器の価格と在庫が、下の購入基準を満たしている（満たすまで買わない。ER605 先行の方針は変えない）

## 基本方針

- 先に補助的な役割で使う。止まっても家のネットが止まらない役割（セグメント間のファイアウォールなど）から始める
- 家の入口のルーターの置き換えは、検証と運用の実績を確認してから行う
- 置き換えるときは、新しい ADR を追加して [ADR 0009](../../adr/0009-router-er605-first.md) を置き換え済みにする
- ER605 は予備機として保管し、戻せる状態にしてから切り替える

## 導入の段階

### Phase 1: 機器の購入

- [ ] 機器の価格と在庫を定期的に確認し、購入基準を満たしたら購入する
- [ ] NIC のチップ型番と、FreeBSD / OPNsense での動作実績を購入前に確認する
- [ ] N100 のミニ PC と、[PCIe 拡張できる Tiny PC + PCIe NIC](#代替案-pcie-拡張できる-tiny-pc--pcie-nic) のどちらにするかを、価格・消費電力・騒音で比べて決める

### Phase 2: 補助的な役割での検証

- [ ] 止まっても影響が小さい役割（セグメント間のファイアウォールなど）から試す
- [ ] TP-Link ルーターのファイアウォールとの役割分担を決め、ADR に残す
- [ ] 検証用ネットワークで VLAN・DHCP・DNS・ファイアウォール・VPN を試す
- [ ] 設定のバックアップと復旧手順を作る

### Phase 3: ER605 の後継への切り替え

- [ ] 検証の結果と運用の実績を見て、切り替えの可否を判断する
- [ ] 切り替えの ADR を書く（ADR 0009 を置き換える）
- [ ] 戻し手順を書く（戻し先は ER605。Omada のバックアップと OPNsense の設定を事前に保存する）
- [ ] Omada との役割分担（スイッチ・AP は Omada のまま）を整理し、設計書・構成図を更新する
- [ ] ER605 を OPNsense に置き換える。ER605 は予備機として保管する

## 購入基準

ルーターは安定性が最重要なので、安さだけで妥協しない。条件を満たす製品がなければ購入を延期する。

| 項目 | 基準 |
| --- | --- |
| CPU | Intel N100 / N150 相当以上（代替: N5105 / N6005）。IDS/IPS や高速回線を使うなら再評価 |
| NIC | Intel 製 2.5GbE × 4 ポート（最低 2 ポート）。802.1Q の VLAN が使える。チップ型番と FreeBSD / OPNsense での動作実績を購入前に確認 |
| メモリ | 8GB 以上（余裕を見るなら 16GB）。交換できること |
| ストレージ | 64〜128GB 以上の SSD。eMMC より交換できる SSD を優先 |
| その他 | x86-64、UEFI 起動、AES-NI、ファンレスまたは静音、BIOS で自動電源復帰を設定できる |
| 価格 | 総額 3 万円前後（RAM・SSD・AC アダプタ・送料を含む）。許容は 4 万円まで、4 万円超は原則見送り |

購入先:

- 国内販売（Amazon.co.jp など）: 保証と返品対応を優先する
- 海外通販（AliExpress の CWWK・Topton など）: 価格と NIC 構成の選択肢が利点。販売者の評価、返品条件、電源仕様を確認する。同じ型番でも NIC や基板のリビジョンが違うことがある
- 中古（国内中古 PC ショップ、メルカリ、ヤフオク）: 価格差が大きいときだけ。SSD の状態、付属品、BIOS ロックを確認する

避ける製品:

- Realtek NIC のみ、または NIC のチップ型番が不明
- 消費電力が大きい旧世代のデスクトップ PC、ファン騒音が大きい製品
- SSD や RAM を交換できない製品
- 保証がなく価格の利点も小さい中古品
- ルーター用途には過剰な高性能 CPU の機種

Realtek NIC も動くが、安定運用のため Intel NIC を優先する。判断の優先順位は、OPNsense との互換性、NIC の品質とポート構成、24 時間稼働の安定性、消費電力、総額、静音性、CPU 性能、サイズの順。

## 代替案: PCIe 拡張できる Tiny PC + PCIe NIC

N100 のミニ PC を買う代わりに、PCIe スロットを持つ中古の Tiny PC（Lenovo ThinkCentre M720q / M90q Tiny など）に、PCIe の NIC を取り付けて OPNsense 機にする選択肢がある。NIC を自分で選べるのが利点。

| 項目 | 内容 |
| --- | --- |
| 候補の機種 | ThinkCentre M720q（ライザーカード経由の PCIe スロット）、M90q Tiny（PCIe x16 形状のスロット）など。スロットの有無・形状・電気的な幅は機種と世代で違うので、購入前に型番ごとに確認する |
| 取り付ける NIC | Intel 製のロープロファイル対応カード。1GbE なら i350-T2 / T4、2.5GbE なら I225 / I226 搭載カード、10GbE なら X540 / X550 / X710 系など。Realtek 製は避ける（購入基準と同じ） |
| 利点 | NIC のチップを選べる（Intel で固定できる）。ポート数を後から増やせる。中古なら本体が安い。CPU が N100 より速く、IDS/IPS や高速回線にも余裕がある。メモリ・SSD を交換できる |
| 注意点 | N100 より消費電力が大きい（アイドルでも 10W 前後以上）。ファンの音がある。ライザーカードとロープロファイルのブラケットが必要で、本体に付属しないことがある。サーバーの NIC 用ブラケットは長さが合わない場合がある。中古品の状態（BIOS ロック、SSD の摩耗）を確認する |
| 現行の ThinkCentre | Proxmox ホストの ThinkCentre M70q Tiny は別の用途で使っている。M70q は PCIe スロットがなく NIC を増設できないため、OPNsense 用には PCIe スロットのある別の 1 台を用意する |

購入基準の「NIC」「価格」は、この案にも同じ考え方で当てはめる。総額は、本体・NIC・ライザー・RAM・SSD・AC アダプタ・送料を合わせて見る。N100 のミニ PC と比べて、価格・消費電力・騒音のどちらを優先するかで選ぶ。
