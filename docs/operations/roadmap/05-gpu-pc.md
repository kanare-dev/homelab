# GPU 搭載ゲーミング PC 兼ホームサーバー

[ロードマップ](README.md)の大型計画。未着手。構成を決めて購入に進むときは、設計書（`docs/architecture/`）と構成図の更新、ADR の追加を同じ変更で行う。

## 目的

- PC ゲームへの入門
- ローカル LLM・機械学習の実行環境構築
- GPU 計算リソースのホームラボへの統合
- MacBook Pro からのリモート操作環境構築
- 将来的なハードウェア・サーバー用途の拡張

## 基本方針

- 予算: 20〜25 万円
- BTO の Windows デスクトップ PC を購入
- 普段はヘッドレスで運用し、MacBook Pro からリモート接続
- 必要に応じてディスプレイ・キーボードを直接接続可能にする
- GPU 性能だけでなく、拡張性・静音性・冷却性能を重視
- 常時稼働サービスは既存 ThinkCentre に配置し、GPU 搭載 PC は必要時のみ起動
- 「高性能なゲーミング PC」ではなく「ゲームもできる拡張性の高い GPU 計算ノード」を買う
- 初期 OS は Windows 11 のベアメタル。Proxmox VE は将来の検証・移行候補

## ハードウェア構成（候補）

| パーツ | 推奨構成 | 備考 |
| --- | --- | --- |
| CPU | Ryzen 5 7600 / Ryzen 7 7700（AM5） | 内蔵 GPU 付きが望ましい（Proxmox の GPU パススルー検証用）。Ryzen 5 7500F は内蔵 GPU なし |
| GPU | NVIDIA RTX 5060 Ti 16GB 以上 | LLM は VRAM 容量を重視。CUDA・PyTorch の互換性から NVIDIA。RTX 5070 12GB より 5060 Ti 16GB が適する場合がある |
| RAM | DDR5 32GB（将来 64GB 以上へ拡張） | 16GB × 2 のデュアルチャネルが望ましい |
| SSD | NVMe 1TB 以上 | M.2 の空きを確認。将来 Linux・VM 用に増設 |
| マザーボード | B650 / B850（拡張性重視） | メーカー・型番を確認 |
| 電源 | 750W 80 PLUS Gold 以上 | メーカー・型番、GPU 補助電源コネクタを確認。品質・静音性を重視 |
| ケース | ATX ミドルタワー（静音・冷却・拡張性重視） | 大型 GPU が入り、SSD・ファンを増設できる |
| ネットワーク | 有線 LAN（可能なら 2.5GbE） | |

購入前の確認事項:

- RAM スロット数・最大搭載容量
- M.2 スロット数・空きスロット
- PCIe スロット構成
- 将来の大型 GPU への交換可否
- 電源容量・補助電源コネクタ
- Wake-on-LAN 対応（UEFI・NIC）
- IOMMU / AMD-Vi 対応（将来の GPU パススルー用）
- BTO メーカーの保証条件とパーツ交換制限

## 機種比較の優先順位

上から順に重視する。GPU・CPU の性能だけでなく、将来の拡張性とサーバー用途への転用しやすさを見る。

1. GPU VRAM 16GB 以上
2. 予算 20〜25 万円以内
3. AM5 プラットフォーム
4. RAM 32GB 以上
5. SSD 1TB 以上
6. マザーボードの拡張性
7. 電源・ケースの品質
8. Wake-on-LAN・リモート運用への適性
9. 保証・サポート・納期
10. デザイン・RGB ライティング

予算を超える場合:

- 妥協してよい: CPU を Ryzen 7 から Ryzen 5 へ、SSD を 1TB に抑えて後から増設、RGB などの装飾を省く、高価な水冷を避ける
- 妥協しない: GPU VRAM 16GB、AM5、マザーボードの拡張性、電源の品質、ケースの冷却性能
- RAM は最初から 32GB を確保する。後から足すなら、スロット構成と価格を先に確認する

## OS・ソフトウェア構成

- ホスト OS: Windows 11
- Linux 環境: WSL2（Ubuntu）
- ゲーム: Steam
- リモートゲーミング: Sunshine（ホスト）+ Moonlight（Mac）
- 開発・管理: SSH / VS Code Remote
- コンテナ: Docker
- ローカル LLM: Ollama / Open WebUI
- 機械学習: CUDA / PyTorch
- GPU 監視: NVIDIA SMI / Prometheus / Grafana

## ネットワーク・運用構成

- MacBook Pro: メイン操作端末
- GPU 搭載 PC: ゲーム・LLM 推論・機械学習
- ThinkCentre: DNS・監視・Docker 等の常時稼働サービス
- Omada: LAN・VLAN・ネットワーク管理

運用方針:

- GPU 搭載 PC は有線 LAN 接続
- MacBook から Moonlight でゲームをプレイ
- SSH で WSL2 の Linux 開発環境へ接続
- Wake-on-LAN でリモート起動
- 未使用時はシャットダウンして消費電力を削減
- ヘッドレス運用に必要な仮想ディスプレイを設定
- 障害時は物理ディスプレイ・キーボードを接続して復旧
- Open WebUI 等の常時稼働フロントエンドは ThinkCentre に配置し、GPU 搭載 PC 上の Ollama API へ接続

## 設計上の注意点

- ゲームの互換性を優先し、初期構成は Windows 11 を採用
- Proxmox は初期導入せず、将来の検証対象とする
- GPU の VM 間共有には技術的制約がある
- GPU 搭載 PC の停止中は LLM API を利用できない
- Windows Update による再起動・サービス停止を考慮する
- WSL2 のサービス自動起動・復旧方法は別途設計する
- Wake-on-LAN は機種・設定によって動作条件が異なる
- 24 時間稼働による電気代・発熱・騒音に注意する

## 最終的な目標

MacBook Pro をメイン端末として、必要なときに GPU 搭載 PC をリモート起動し、ゲーム・LLM 推論・機械学習を実行できる環境を構築する。

既存 ThinkCentre を常時稼働サーバーとして活用しながら、GPU 搭載 PC をオンデマンドの高性能計算ノードとして統合する。

将来的には、GPU リソースをホームラボ内の複数サービスや Kubernetes ワークロードから利用できる構成へ発展させる。
