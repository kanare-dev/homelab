# Omada 導入・VLAN 化・OPNsense 導入

[ロードマップ](README.md)の大型計画。ER605・SG2008P・EAP（AP）で Omada のネットワークを作り、VLAN で分離し、そのあとに OPNsense を学習用に足す。設計は完了、機器は未購入で未着手。

詳細は設計書と ADR にある。この文書は、進行の順序とチェック項目だけを持つ。

## 目的

- ルーター・スイッチ・AP を Omada で一元管理する
- 管理・サーバー・クライアント・IoT・ゲストを VLAN で分け、セグメント間の通信を制限する
- OPNsense（N100）で、ファイアウォールなどネットワーク技術を学ぶ

## 基本方針

- 機器は買う順に 4 段階に分ける。段階 1〜2 の間は IP を変えない
- VLAN への切り替えは、全ホストを一斉に行う（段階 3）
- 家の入口のルーターは ER605 のままにする。OPNsense は、止まっても影響が小さい役割から試す
- 各段階で戻し方を決めてから着手する（戻し先は直前の段階の状態）

## 導入の段階

### 段階 1: ルーターの交換と Omada コントローラー

- [ ] ER605 **V2** を購入する（型番と、コントローラーのバージョンとの対応を購入前に確認する）
- [ ] Omada コントローラーを Proxmox 上の VM として立てる
- [ ] ER605 の LAN アドレスを `192.168.11.1/24` に変更してから、コントローラーで採用する
- [ ] ルーターを Buffalo から ER605 に交換し、Buffalo を AP モードにする（IP は変えない）
- [ ] 設計書・構成図を更新する

### 段階 2: Managed Switch

- [ ] SG2008P を購入する（PoE の電力予算は 62W。将来の AP の台数を確認する）
- [ ] スイッチをコントローラーで採用し、Proxmox などをつなぐ（VLAN は使わない）
- [ ] 設計書・構成図を更新する

### 段階 3: VLAN と `10.x` への一斉切り替え

- [ ] コントローラーモードの ACL で、LAN → LAN を制限できるか確認する（段階 3 の前）
- [ ] mDNS の中継（Clients ↔ IoT）が動くか確認する。動かなければ、段階 4 まで有線のテレビを Clients に置く
- [ ] TO-BE の構成図を描く
- [ ] 物理設置（ThinkCentre・ルーター・スイッチの置き場所、通気、電源、ケーブル）を決める
- [ ] 戻し手順を書く（戻し先は段階 2 の状態。Omada のバックアップと `terraform state` を事前に保存する）
- [ ] VLAN10 Management / VLAN20 Servers / VLAN30 Clients / VLAN40 IoT / VLAN50 Guests へ全ホストを一斉に切り替える
- [ ] 設計書・構成図・Terraform・Ansible・DNS の IP を更新する

### 段階 4: AP（EAP）

- [ ] AP の機種を選ぶ（Wi-Fi 6 世代の日本での入手性・価格・技適を、段階 3 の後に確認する）
- [ ] AP を設置し、SSID と VLAN を対応させる（設置場所は電波の届き方で決める）
- [ ] Buffalo を退役または予備にする

## OPNsense の導入

段階 3 のあとに、学習用のプロジェクトとして始める。現在は機器の価格が高いため、購入基準を満たす価格になるまで買わない（ER605 先行の方針は変えない）。

- [ ] 機器の価格と在庫を定期的に確認し、購入基準を満たしたら購入する
- [ ] 止まっても影響が小さい役割（セグメント間のファイアウォールなど）から試す
- [ ] TP-Link ルーターのファイアウォールとの役割分担を決め、ADR に残す
- [ ] 検証用ネットワークで VLAN・DHCP・DNS・ファイアウォール・VPN を試し、設定のバックアップと復旧手順を作る
- [ ] 家の入口のルーターを OPNsense に替えるかは、運用の実績を見てから判断する（替える場合も ER605 は予備機として保管する）

### 購入基準

ルーターは安定性が最重要なので、安さだけで妥協しない。条件を満たす製品がなければ購入を延期する。

| 項目 | 基準 |
| --- | --- |
| CPU | Intel N100 / N150 相当以上（代替: N5105 / N6005）。IDS/IPS や高速回線を使うなら再評価 |
| NIC | Intel 製 2.5GbE × 4 ポート（最低 2 ポート）。802.1Q の VLAN が使える。チップ型番と FreeBSD / OPNsense での動作実績を購入前に確認 |
| メモリ | 8GB 以上（余裕を見るなら 16GB）。交換できること |
| ストレージ | 64〜128GB 以上の SSD。eMMC より交換できる SSD を優先 |
| その他 | x86-64、UEFI 起動、AES-NI、ファンレスまたは静音、BIOS で自動電源復帰を設定できる |
| 価格 | 総額 3 万円前後（RAM・SSD・AC アダプタ・送料を含む）。許容は 4 万円まで、4 万円超は原則見送り |

購入先:

- 国内販売（Amazon.co.jp など）: 保証と返品対応を優先する
- 海外通販（AliExpress の CWWK・Topton など）: 価格と NIC 構成の選択肢が利点。販売者の評価、返品条件、電源仕様を確認する。同じ型番でも NIC や基板のリビジョンが違うことがある
- 中古（国内中古 PC ショップ、メルカリ、ヤフオク）: 価格差が大きいときだけ。SSD の状態、付属品、BIOS ロックを確認する

避ける製品:

- Realtek NIC のみ、または NIC のチップ型番が不明
- 消費電力が大きい旧世代のデスクトップ PC、ファン騒音が大きい製品
- SSD や RAM を交換できない製品
- 保証がなく価格の利点も小さい中古品
- ルーター用途には過剰な高性能 CPU の機種

Realtek NIC も動くが、安定運用のため Intel NIC を優先する。判断の優先順位は、OPNsense との互換性、NIC の品質とポート構成、24 時間稼働の安定性、消費電力、総額、静音性、CPU 性能、サイズの順。
