# 基本設計（HLD）

homelab の基本設計。構成の全体像と、方式に関わる方針を、6 つの章に分けてまとめる。個別のサービスの設定や、IP アドレスのような具体的な値は、[詳細設計](../lld/README.md)に書く。設計判断の経緯は [ADR](../../adr/README.md)、運用手順は [Runbook](../../operations/runbooks/README.md) にある。

## 目次

| 章 | 内容 |
| --- | --- |
| [第1章 システム構成・環境](01-system.md) | 構成図、目的、この構成にした理由、前提と制約、物理構成、論理構成、ソフトウェア構成 |
| [第2章 信頼性](02-reliability.md) | 単一障害点、起動順序、変更の確かさ、障害の検知、再発防止、災害対策（バックアップ、再構築の手順） |
| [第3章 運用・保守](03-operations.md) | 運用の方針、更新の方針、移行性（移行シナリオ、移行前のチェックリスト） |
| [第4章 性能・拡張性](04-performance.md) | ホストの資源と配分、ストレージの設計、資源の見張り方、拡張の方針 |
| [第5章 ネットワーク](05-network.md) | ドメイン命名規約、外部接続（Tailscale、外部サービスへの依存） |
| [第6章 セキュリティ](06-security.md) | 脅威の想定、秘密情報、アクセス制御、未対応の項目 |

## 書き方の決まり

- 構成を変えたら、該当する章を同じ変更で更新する。
- 数値の根拠がない目標は「暫定」と明記する。実測が取れたら更新する。
- 機密値は書かない（リポジトリは公開）。
