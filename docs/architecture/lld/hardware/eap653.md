## 仕様（製品ページ）

### ハードウェア

| 項目 | 内容 |
| --- | --- |
| 規格 | IEEE 802.11a/b/g/n/ac/ax（Wi-Fi 6） |
| 速度 | 5GHz: 2402Mbps、2.4GHz: 574Mbps（製品名の AX3000 は、合計 2976Mbps を丸めた値） |
| アンテナ | 内蔵。2.4GHz: 4dBi × 2、5GHz: 5dBi × 2 |
| ポート | ギガビット LAN ポート × 1（IEEE 802.3at 準拠） |
| 電源 | 802.3at PoE、48V パッシブ PoE、12V DC（アダプターは別売りで、TP-Link は販売していない。日本のページは PoE での利用を前提にしている） |

| カバー範囲 | 140㎡（実験室の測定値） |
| 同時接続 | 250 台以上 |
| Bluetooth | V5.2 |
| 寸法 | 160 × 160 × 33.6 mm |
| 設置 | 天井、壁面、ジャンクションボックス（取り付けキット付属） |
| 動作温度 | 日本のページ: 0〜50℃。米国のページ（V3）: 0–40 ℃ |
| 認証 | CE、FCC（技適の記載は、製品ページに見つからない。本体のラベルで確かめる） |

### ソフトウェアの機能

| 分類 | 内容 |
| --- | --- |
| SSID | 最大 16 個（各バンドに最大 8 個）。SSID ごとに VLAN を割り当てられる |
| 管理 | 管理 VLAN に対応。L3 管理に対応 |
| 無線 | バンドステアリング、クライアント間の分離 |
| セキュリティ | WPA/WPA2、WPA3-Personal/Enterprise |
| Omada | メッシュ、シームレスローミング、キャプティブポータルには、Omada のコントローラーが要る |

mDNS（Bonjour）の中継と、必要なコントローラーの版は、製品ページに見つからない（未確認）。Omada の資料では、AP の VLAN 間の Bonjour にはコントローラー v5.9 以降が必要とされる（[ロードマップ 04](../../../operations/roadmap/04-network-omada-vlan.md#vlan-設計の未決事項検討中)）。今のコントローラーは 6.3 系である。

## 使うときの注意

| 項目 | 内容 |
| --- | --- |
| 給電 | SG2210P の PoE+（802.3at。1 ポート 30 W まで、合計 61 W）から給電する。最大消費電力は 15.5 W 以下なので、1 台なら予算に収まる（[SG2210P の資料](sg2210p.md)） |
| SSID と VLAN | 1 本の LAN ケーブルで、Management（AP 自身）と、SSID ごとの VLAN（Trusted、IoT、Guests）を通す。スイッチのポートは trunk にする |
| 2.4GHz の端末 | Tapo C200 などの IoT の機器は 2.4GHz にしか対応しない。`Onda-IoT` は 2.4GHz だけで出す計画（[ADR-0042](../../../adr/0042-ssid-names-by-vlan.md)） |
| 名前 | ホスト名は `ap01`。Buffalo を退役させたら、名前を引き継ぐ（[ADR-0035](../../../adr/0035-network-device-names-by-role.md)） |
