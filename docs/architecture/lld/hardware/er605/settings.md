# ER605（TP-Link ルーター）

TP-Link ER605 V2 の設定値（詳細設計）。段階 1・2（2026-11-06）で Buffalo と入れ替えた。**この文書を、設定値の正とする。** 製品の仕様とファームウェアは[ER605 の資料](spec.md)、コントローラーは[Omada コントローラー](../../network/omada-controller.md)、VLAN 化のあとの設定は[第5章 ネットワーク](../../../hld/05-network.md)、移行の手順は[移行計画](../../../../operations/roadmap/10-er605-sg2210p-migration-plan.md)にある。

> [!NOTE]
> 作成日は 2026-11-03。**秘密の値（管理者のパスワード）と、機器の MAC アドレスは書かない**（リポジトリは公開）。

## 位置づけ

| 時期 | 役割 | 管理 |
| --- | --- | --- |
| 設置前 | 工場出荷時に戻したあと、スタンドアロンで LAN と DHCP を設定した（2026-11-03） | 本体の画面 |
| **現在**（段階 1・2 の後。2026-11-06〜） | 家のルーター（NAT、DHCP）。既定のネットワークは Management（VLAN10、`10.77.10.0/24`）。VLAN1 は使わない（2026-11-20 に統合。[ADR-0032](../../../../adr/0032-merge-default-network-into-management-vlan10.md)） | コントローラー（本体の画面は使えなくなった） |
| 段階 3 の後 | 各 VLAN のゲートウェイ、DHCP、ACL（`10.77.<VLAN>.1`） | コントローラー |

## 運用

- 設定を変えたら、**同じ変更でこの文書を更新**し、[変更履歴](#変更履歴)に 1 行足す。コントローラー側の変更は、[Omada コントローラー](../../network/omada-controller.md)の変更履歴にも書く。
- 設定を変えたあとは、コントローラーのバックアップを取る（[手順](../../network/omada-controller.md#運用)）。

## 設定値

### ポート

| ポート | 接続先 | 備考 |
| --- | --- | --- |
| p1（WAN） | 壁の LAN ポート（ケーブル A） | 接続済み（2026-11-06）。MAC クローンなしで IP を取れた |
| p2（WAN/LAN） | SG2210P の p1 | 接続済み。LAN として動いている（最初から LAN。2026-11-06 に確認） |
| p3（WAN/LAN） | 使わない（段階 1・2 の確認のとき、Mac を一時的に繋いだ） | |
| p4〜p5（LAN） | 使わない | |

ポートの種類は、p1 が WAN 専用、p2 と p3 が WAN/LAN の切り替え、p4 と p5 が LAN 専用（運用者が本体で確認。2026-11-06）。

### WAN

| 項目 | 値 |
| --- | --- |
| 接続方法 | DHCP（上流は建物の共用ルーター。`172.22.0.0/21` の範囲の見込み）。2026-11-06 に、ER605 を繋いで IP を取れた |
| MAC アドレス | 既定（MAC クローンは不要だった。上流は、MAC で絞っていない。2026-11-06 に確認） |
| IPv6 | 使わない（[ADR-0017](../../../../adr/0017-ipv6-disabled.md)）。設定値は未確認 |

### LAN と DHCP

| 項目 | 値 |
| --- | --- |
| LAN 側 IP アドレス | `10.77.10.1` / `255.255.255.0`（**2026-11-20 に変更**。VLAN10、名前 `Management(Default)`。旧 `10.77.1.1`（VLAN1）、その前は `192.168.11.1`。ADR-0032 で VLAN10 に統合した） |
| DHCP サーバー | 使用する。範囲 `10.77.10.240`〜`10.77.10.250`（復旧ポート p8 に繋いだ端末向け）、リース 60 分（画面の値。2026-11-20） |
| 配る DNS | ルーター（`10.77.10.1`。2026-11-20 に、`10.77.1.1` から付け替え）。**2026-11-17 に変更**（旧 `192.168.11.11`（`vm-infra`）。段階 3 で `vm-infra` が `10.77.20.10` に移ったため。[ADR-0028](../../../../adr/0028-defer-management-vlan10.md)）。`1.1.1.1` は併記しない（[ADR-0024](../../../../adr/0024-dhcp-dns-single-no-fallback.md)）。ER605 の DNS プロキシが外部の名前を引く。内部の名前（`*.lab.kanare.dev`）は引けないので、IP で入る |
| 配るドメイン名 | 配らない |
| 固定割り当て（予約） | なし（Buffalo の固定リース 1 件は、移さない。[移行計画](../../../../operations/roadmap/10-er605-sg2210p-migration-plan.md)） |

以上は、運用者がスタンドアロンで設定した値（2026-11-03、運用者の申告。画面の値は未確認）。

### VLAN のネットワーク（段階 3 の準備）

## 見直したい項目・未確認

- 採用後の設定値（LAN、DHCP、NTP・時刻、ファイアウォール、UPnP）を、コントローラーの画面から書き写し直す（採用のあと、LAN と DHCP が変わっていないことは、2026-11-06 に確認した）。
- 管理者アカウント（コントローラーが機器に入るためのアカウント）が、初期値のままではないこと。

確認済み（2026-11-06）: p2 は最初から LAN として動いた。上流は MAC で絞っていない（MAC クローンなしで IP を取れた）。
