## 書き方

- ファイル名は `NNNN-<英語のタイトル>.md`。番号は連番で、再利用しない。
- 判断を変えるときは、古い ADR を書き換えず、新しい ADR を追加して古い方のステータスを「置き換え済み（→ NNNN）」にする。
- 日付が記録に残っていないものは「記録なし」とする。推測で書かない。
- 各 ADR は、背景・決定・理由・代替案・影響と再検討の条件を書く。構成や手順の詳細は書かず、該当する文書へリンクする。
