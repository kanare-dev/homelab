# 0041. Omada の設定値は Open API で取り出してリポジトリに置き、文書とのずれを見る

- ステータス: 採用
- 日付: 2026-11-28

## 背景

[ADR-0040](0040-config-source-of-truth-by-location.md) で、画面にしか置けない設定（Omada コントローラーなど）は、詳細設計書（パラメーターシート）を正にすると決めた。Omada の設定画面は、サイトのメニューだけで 40 ほどあり、多くは既定値のままである。既定値まで手で写すと、写し間違いが起きる。写したあとに実機と文書がずれても、気づく手段がない。

2026-11-28 に、Omada コントローラー（6.3.0.111）の Open API を調べた。仕様書（`/v3/api-docs/00 All`）は認証なしで取れ、設定の分野ごとに読み取り（GET）の窓口がある。omada-exporter 用に作った Viewer の Open API のクライアント（[ADR-0039](0039-omada-metrics-via-omada-exporter.md)）で、約 50 の窓口を試すと、バックアップのスケジュールを除いて読めた。ゲートウェイの ACL（21 件）、LAN、グループ、サイトの設定、機器ごとの設定も取れた。

## 決定

1. Omada の設定値を、Open API で取り出すスクリプト（`tools/omada-export.py`、`make omada-export`）を作る。GET だけを呼び、認証は omada-exporter の Viewer のクライアント（SOPS）を使う。
2. 取り出した値は、JSON にして `docs/architecture/lld/network/omada/snapshot/` に置き、Git で管理する（案 A）。画面のメニューの区分ごとに 1 ファイルにする。
3. リポジトリは公開なので、書き出す前に、秘密の値（パスワード、鍵）、機器の MAC アドレス（機器の名前に置き換える）、シリアル番号を落とす。実行のたびに変わる値（状態、統計、時刻）も落とし、設定が変わらなければ差分が出ないようにする。
4. 正は、これまでどおり [Omada コントローラーの設定値](../architecture/lld/network/omada-controller.md)（パラメーターシート）とする。取り出した値は「実機の姿」で、パラメーターシートとの食い違いが、ずれである。Omada の設定を変えたら、`make omada-export` を流し、変わった値を `git diff` で確かめて、パラメーターシートと同じ変更でコミットする。

## 理由

- 値を写すのはスクリプトに任せ、人は「なぜその値か」を書くことに集中できる。既定値の写し間違いがなくなる。
- Git に置くと、実機の変更が `git diff` に出る。画面で知らずに変わった設定（[INC-2026-11-08](../operations/incidents/2026-11-08-sg2210p-native-vlan-overwrite.md) のような上書き）にも気づける。
- 公式の API で、スキーマが公開されている。MongoDB を直接読むより、版が変わっても壊れにくい。
- 新しい認証情報を作らずに済む。

## 代替案

| 案 | 採らなかった理由 |
| --- | --- |
| 取り出した値をリポジトリに置かず、手で書いたパラメーターシートと比べるだけにする（案 B） | 実機の変更が履歴に残らない。比べる処理を、パラメーターシートの書式に合わせて作り込む必要がある |
| `vm-omada` の MongoDB を直接読む | 内部のスキーマが非公開で、版が変わると壊れやすい |
| バックアップファイル（`.cfg`）を読む | 独自の形式か暗号化で、読めない。認証情報も入る |
| 手で写すだけにする | 量が多く、写し間違いと、ずれに気づけない問題が残る |

## 影響と再検討の条件

- Viewer の権限でも、機器のデバイスアカウントのパスワードが平文で読める（2026-11-28 に確認）。スクリプトは書き出す前に落とすが、認証情報そのものの扱いには注意が要る。危険と対策は、[Omada コントローラーの設定値](../architecture/lld/network/omada-controller.md#open-api-と設定値の書き出し)に書いた。
- コントローラーの版を上げると、API の応答の形が変わり、書き出した値に大きな差分が出ることがある。そのときは、差分が版の違いによるものかを確かめてからコミットする。
- 取り出せない設定（バックアップのスケジュールなど）は、パラメーターシートに手で書く。
