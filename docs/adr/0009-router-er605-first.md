# 0009. ルーターは ER605 V2 を先に導入し、OPNsense は後で学習用に足す

- ステータス: 採用
- 日付: 2026-10-24

## 背景

ルーターの候補は 2 つあった。

- 案A: TP-Link ER605（V2）。Omada コントローラーでスイッチ・AP と一元管理できる。
- 案B: Topton N100 + OPNsense（2.5GbE × 4、RAM 8GB、SSD 128GB 程度。予算は 2〜3 万円）。ファイアウォール・VLAN・VPN を柔軟に設定できる。ルーターは Omada の一元管理の外になる（スイッチ・AP は Omada で併用できる）。

自宅の有線回線は、下り約 530Mbps・上り約 600Mbps。ホームラボでネットワーク技術を学ぶことと、Omada による統合管理も重視している。

## 決定

- 先に **ER605 V2** を導入する。[VLAN 設計](../architecture/08-vlan-design.md)の段階 1（IP は変えずにルーターを交換）から始める。
- **OPNsense（N100）は後で、学習用のプロジェクトとして足す。** 時期は VLAN 導入（段階 3）が終わったあと。家の入口のルーターは ER605 のままにし、OPNsense はセグメント間のファイアウォールなど、止まっても影響が小さい役割で試す。

## 理由

- 回線が 1Gbps 未満なので、1GbE の ER605 V2 で足りる。N100 の 2.5GbE は、今は活きない。
- VLAN 設計と [ADR 0003](0003-vlan-address-scheme.md)・[ADR 0004](0004-vlan-cutover-all-at-once.md) は ER605 + Omada を前提に書いてあり、そのまま使える。B を先にすると、段階 1 と Omada コントローラーまわりを書き直すことになる。
- Omada で、ルーター・スイッチ・AP を一元管理できる。B は、ルーターだけ別の画面になる。
- 費用が小さい（約 1 万円）。B は 2〜3 万円で、設定ミスや更新の失敗が、家のネットの停止につながる。
- B は A の後から足せる。先に A を入れても、B の学習機会は失われない。

## 代替案

| 案 | 判断 |
| --- | --- |
| B を先に導入する | 見送り。学習を最優先にして、止まることを許容するなら選べる。その場合は、Buffalo を予備のルーターとして残し、OPNsense の設定のバックアップ方針を決める |
| ER707-M2（2.5GbE の Omada ルーター） | 見送り。回線が 1Gbps を超える見込みが出たら再検討する。価格・在庫は未確認 |
| ER7206 | 見送り。二重 NAT の環境では過剰 |
| MikroTik | 見送り。Omada との併用を想定していない |
| OPNsense を Proxmox の VM で動かす | 見送り。ホストの NIC が 1 つで、ルーターには向かない |

## 影響と再検討の条件

- 機器の導入は [VLAN 設計](../architecture/08-vlan-design.md#導入の段階)の 4 段階のまま。ER605 V2 の購入前には、型番（V2、「法人限定」の販売ページ）を確認する。
- 次の場合は、新しい ADR を追加して置き換える。
  - 回線が 1Gbps を超える。
  - ER605 のファイアウォール機能が足りなくなった。
  - OPNsense を、家の入口のルーターにしたくなった。
- OPNsense の位置づけ（ファイアウォールを ER605 で賄うか、OPNsense を別に立てるか）は、VLAN 設計の「未決事項」に残っている。段階 3 のあとに決める。
