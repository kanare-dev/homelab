# 0035. ネットワーク機器のホスト名は、型番ではなく役割と番号で付ける

- ステータス: 採用（Omada のデバイス名は 2026-11-27 に適用済み）
- 日付: 2026-11-27

## 背景

ER605 と SG2210P には、Omada のデバイス名として、型番の小文字（`er605`、`sg2210p`）を付けていた（2026-11-06）。AP を足すときも、同じ付け方で `eap-xxx` などにする予定だった（[Omada コントローラーと管理対象機器](../architecture/lld/network/omada-controller.md)）。

一方、Proxmox ホストは、2026-11-24 に `pve` から `pve01` に変えた。ホストが増えても名前が重ならないように、役割に番号を付けた形である（[手順書 26](../operations/runbooks/26-rename-pve-host-to-pve01.md)）。

構成図にネットワーク機器のホスト名を書くことと、固定 IP のホストに DNS のレコードを揃えること（[ロードマップ 15](../operations/roadmap/15-host-names-and-dns-records.md)。検討中）を考える中で、運用者は、ネットワーク機器の名前の付け方を決めることになった。

## 決定

1. ネットワーク機器のホスト名は、**役割の略と 2 桁の番号**で付ける。ルーターは `rtr01`、スイッチは `sw01`、AP は `ap01` とする。同じ役割の機器を足すときは、番号を進める（`sw02`）。
2. 今の機器には、次の名前を付ける。

   | 機器 | 今の名前 | 新しい名前 |
   | --- | --- | --- |
   | ER605（ルーター、`10.77.10.1`） | `er605`（Omada のデバイス名） | `rtr01` |
   | SG2210P（スイッチ、`10.77.10.2`） | `sg2210p`（Omada のデバイス名） | `sw01` |
   | Buffalo WSR-1800AX4P（AP、`10.77.30.50`） | なし | `ap01` |

3. 機器を替えるときは、同じ役割の名前を、新しい機器に譲る。Omada の AP を導入して Buffalo を退役させるときは、`ap01` を新しい AP に付ける。ER605 を OPNsense に置き換えるときも、`rtr01` を引き継ぐ。
4. Omada のデバイス名、DNS の名前（採るとき。ロードマップ 15 の案 1）、構成図のホスト名は、同じ名前に揃える。
5. VM の名前（`vm-` で始まる名前）と、Proxmox ホストの `pve01` は、この決定では変えない。

## 理由

- ルーターは、[OPNsense への置き換え](../operations/roadmap/08-network-opnsense.md)を計画している。型番の名前は、機器を替えると中身と合わなくなる。役割の名前なら、替えても使い続けられる。
- 役割と番号の形は、`pve01` と付け方が揃う。短い略（`rtr`、`sw`、`ap`）にしたのも、`pve01` の短さに合わせるためである。
- 機種は、設計書と構成図で分かるので、名前に入れなくてよい。

## 代替案

| 案 | 採らなかった理由 |
| --- | --- |
| 型番の名前のまま（`er605`、`sg2210p`） | 機器を替えると、名前と中身が合わなくなる。`pve01` と付け方が揃わない |
| 長い役割の名前（`router01`、`switch01`） | `pve01` の短さと揃わない。構成図とコマンドで長くなる |
| Buffalo を退役させたあと、新しい AP に `ap02` を付ける | 同時に動く AP は 1 台なので、番号を進める意味が薄い。役割の名前は、その役割を担う機器に付けると決めた |

## 結果

- Omada のデバイス名は GUI でしか変えられないので、文書を先に直し、マージしてから実機を変える（[ADR-0033](0033-docs-first-by-change-type-and-diagram-order.md)）。
- 実機を変えたら、[Omada コントローラーと管理対象機器](../architecture/lld/network/omada-controller.md)の「未適用」を外し、`README.md` のホストの表と、現状（as-is）の構成図を直す。
- Buffalo は Omada の管理対象ではない。`ap01` は、まず設計書と構成図での呼び名として使う。Buffalo の画面で機器名を変えるかは、変えるときに決める。
