# 0003. VLAN のアドレス体系を `10.<VLAN>.0.0/24` にする

- ステータス: 採用（VLAN は未適用）
- 日付: 2026-10-23

## 背景

TP-Link への移行と VLAN 化で、全ホストのアドレスを付け替える。現在の `192.168.11.0/24` は Buffalo ルーターの初期値に由来する。外出先から Tailscale で自宅の subnet route に繋ぐため、手元のネットワークとアドレス帯が被ると接続が不安定になる。

## 決定

各 VLAN を `10.<VLAN ID>.0.0/24` にする（例: Servers は `10.20.0.0/24`）。VLAN ID と第 2 オクテットを揃える。

## 理由

- 手元と自宅のサブネットが同じアドレス帯だと、端末は「手元にある」と判断して自宅に送らない。原因の分かりにくい障害になる。
- 家庭用ルーターの初期値は `192.168.x.x` が大半で、`192.168.11.x` なども多い。`10.x` 系は家庭用ではあまり使われず、被りにくい。
- どのみち全ホストのアドレスを変える移行なので、覚え直しの追加負担は小さい。

## 影響と残るリスク

- `10.x` でも `10.10.x.x` のような範囲は、職場や他の VPN で使われていることがある。確定前に、よく行く外出先のアドレス帯と被らないか確認する。
- 上流（引っ越し先）が `10.x` 系を配っていると、WAN 側と被りうる。
