# ER605（TP-Link ルーター）

TP-Link ER605 V2 の設定値（詳細設計）。段階 1・2 で Buffalo と入れ替える。**この文書を、設定値の正とする。** 製品の仕様とファームウェアは[ER605 の資料](spec.md)、コントローラーは[Omada コントローラー](../../services/network/omada-controller.md)、VLAN 化のあとの設定は[VLAN 設計](../../architecture/08-vlan-design.md)、移行の手順は[移行計画](../../operations/roadmap/10-er605-sg2210p-migration-plan.md)にある。

> [!NOTE]
> 作成日は 2026-11-03。**秘密の値（管理者のパスワード）と、機器の MAC アドレスは書かない**（リポジトリは公開）。

## 位置づけ

| 時期 | 役割 | 管理 |
| --- | --- | --- |
| 現在（設置前） | 工場出荷時に戻したあと、スタンドアロンで LAN と DHCP を設定した。配線は未了（WAN は未接続） | 本体の画面 |
| 段階 1・2 の後 | 家のルーター（NAT、DHCP）。アドレスは `192.168.11.0/24` のまま | コントローラー（本体の画面は使えなくなる） |
| 段階 3 の後 | 各 VLAN のゲートウェイ、DHCP、ACL（`10.77.<VLAN>.1`） | コントローラー |

## 運用

- 設定を変えたら、**同じ変更でこの文書を更新**し、[変更履歴](#変更履歴)に 1 行足す。コントローラー側の変更は、[Omada コントローラー](../../services/network/omada-controller.md)の変更履歴にも書く。
- 設定を変えたあとは、コントローラーのバックアップを取る（[手順](../../services/network/omada-controller.md#運用)）。

## 設定値

### ポート

| ポート | 接続先 | 備考 |
| --- | --- | --- |
| p1（WAN） | 壁の LAN ポート（ケーブル A） | 配線は段階 1・2 で行う |
| p2（WAN/LAN） | SG2210P の p1 | 接続済み。LAN として動いているかは未確認 |
| p3（WAN/LAN） | 段階 1・2 の確認のとき、Mac を一時的に繋ぐ | 最終形では使わない |
| p4〜p5（LAN） | 使わない | |

ポートの種類は、p1 が WAN 専用、p2 と p3 が WAN/LAN の切り替え、p4 と p5 が LAN 専用（運用者が本体で確認。2026-11-06）。

### WAN

| 項目 | 値 |
| --- | --- |
| 接続方法 | DHCP（上流は建物の共用ルーター。`172.22.0.0/21` の範囲の見込み） |
| MAC アドレス | 既定。上流が MAC で絞っていて IP を取れなかったときだけ、Buffalo の WAN の MAC にする |
| IPv6 | 使わない（[ADR-0017](../../adr/0017-ipv6-disabled.md)）。設定値は未確認 |

### LAN と DHCP

| 項目 | 値 |
| --- | --- |
| LAN 側 IP アドレス | `192.168.11.1` / `255.255.255.0` |
| DHCP サーバー | 使用する。範囲 `192.168.11.60`〜`192.168.11.99`、リース 48 時間 |
| 配る DNS | `192.168.11.11`（`vm-infra`）だけ。`1.1.1.1` は併記しない（[ADR-0024](../../adr/0024-dhcp-dns-single-no-fallback.md)） |
| 配るドメイン名 | 配らない |
| 固定割り当て（予約） | なし（Buffalo の固定リース 1 件は、移さない。[移行計画](../../operations/roadmap/10-er605-sg2210p-migration-plan.md)） |

以上は、運用者がスタンドアロンで設定した値（2026-11-03、運用者の申告。画面の値は未確認）。

## 見直したい項目・未確認

- p2 が LAN として動くか（接続して、画面の Network > Interface で見る）。
- 上流が MAC で絞っているか（接続して分かる）。
- 採用で、コントローラーの設定が ER605 に反映されたときの値（LAN、DHCP が変わらないか）。
- 採用後は、この文書の設定値を、コントローラーの画面から書き写し直す。
