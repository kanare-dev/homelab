# SG2210P（TP-Link スイッチ）

TP-Link SG2210P V5.30 の設定値（詳細設計）。段階 1・2 で ER605 の下に入れ、段階 3 で VLAN の trunk と access を設定する。**この文書を、設定値の正とする。** 製品の仕様は[SG2210P の資料](spec.md)、コントローラーは[Omada コントローラー](../../services/12-omada-controller.md)、VLAN のポートの割り当ては[VLAN 設計](../../architecture/08-vlan-design.md)、移行の手順は[移行計画](../../operations/roadmap/10-er605-sg2210p-migration-plan.md)にある。

> [!NOTE]
> 作成日は 2026-11-03。**秘密の値と、機器の MAC アドレスは書かない**（リポジトリは公開）。

## 位置づけ

| 時期 | 役割 | 管理 |
| --- | --- | --- |
| 現在 | ER605 の p2 に、SG2210P の p1 で繋いである。未採用で、電源の状態は未確認 | スタンドアロン（標準の設定のまま） |
| 段階 1・2 の後 | 有線のハブ。VLAN は使わない（全ポートが既定の VLAN） | コントローラー |
| 段階 3 の後 | VLAN の trunk（Proxmox）と access（Buffalo、ディスプレイ） | コントローラー |

## 運用

- 設定を変えたら、**同じ変更でこの文書を更新**し、[変更履歴](#変更履歴)に 1 行足す。変更したあとは、コントローラーのバックアップを取る（[手順](../../services/12-omada-controller.md#運用)）。

## 設定値

### ポート（段階 1・2 の後）

| ポート | 接続先 | 備考 |
| --- | --- | --- |
| p1 | ER605 の p2 | アップリンク |
| p2 | Proxmox | 段階 3 で trunk（VLAN10/20/40/50/70 を tag 付き）にする |
| p3 | Buffalo（AP） | 段階 3 で access VLAN30 にする |
| p4 | メインディスプレイ（Dell U2725QE） | 段階 3 で access VLAN30 にする |
| p5–p6 | 空き | 段階 3 のリハーサル用 |
| p7–p8 | 空き | 段階 4 の AP 用に PoE を残す |
| p9–p10 | SFP（使わない） | |

段階 3 のあとの VLAN とポートの設定は、[VLAN 設計](../../architecture/08-vlan-design.md)の表を正とし、適用したらここに書き写す。

### 管理

| 項目 | 値 |
| --- | --- |
| ファームウェア | 未確認（出荷時のまま。採用したあと、コントローラーで更新する） |
| 管理 IP | 段階 1・2 の後は ER605 の DHCP。VLAN 化のあとは `10.77.10.2`（VLAN10） |
| PoE | 全ポート 802.3af/at。電力予算は 61W 前後。段階 4 まで、給電する機器はない |
| IGMP スヌーピング、STP、ストームコントロール | 未確認 |

## 見直したい項目・未確認

- 標準の設定で、全ポートが同じ VLAN の、ただのスイッチとして動くか（段階 1・2 で確認する）。
- 採用前に、SG2210P が ER605 の DHCP から IP を取っているか。
- 採用後は、この文書の設定値を、コントローラーの画面から書き写し直す。
