# 印刷の依頼先と、素材・造形方式の注意点

[10 インチラックマウント](README.md)のモデルを、業者に頼んで印刷する方法をまとめる。自宅に 3D プリンターは無いので、業者に頼むことを前提にする。

> [!NOTE]
> 確認日は 2026-11-01。各社の公式ページと、検索で見つかった比較記事を読んだもの。**料金は、データ（STL か 3MF）をアップロードした実際の見積もりで確認する**（素材・サイズ・形状で大きく変わり、価格改定もある）。注文して確かめたわけではないので、納期・送料・税は目安。

## 結論

- **まず素材を決める。** 作者の推奨は PETG、ABS、ASA。PLA は熱で柔らかくなる。ラックの中は M70q などの熱がこもるので、PLA は避ける。
- **PETG が欲しいなら、国内の業者は見つからなかった。** 海外の V3DPrint（エストニア）と PCBasic が PETG を扱う。JLC3DP の FDM に PETG は無い（ABS と ASA はある）。
- **国内で急ぐ・確実に使いたいなら、DMM.make の MJF ナイロン（PA12）。** 強度と耐熱は FDM の PETG より上だが、素材費が高く、大きな薄板は割高になりやすい。まず見積もりを取る。
- **安く済ませたいなら、JLC3DP の FDM（ASA か ABS）。** 中国からの発送なので、日数と、関税・消費税の扱いを注文前に確認する。
- **データの形式は業者ごとに確認する。** 一部のモデルは 3MF 形式。受け付けない業者には STL に変換して送る（下の「データの形式」）。

## 選び方

次の順に絞る。

1. **素材**: PETG が要るか、ASA / ABS でよいかを決める。PLA は避ける。
   - 熱がこもる閉じたラックなら ASA か ABS か MJF ナイロン。
   - 開いたラックで、冷却が十分なら PETG でもよい。
2. **造形サイズ**: データの外形（幅約 250 mm）が業者の上限に入るか。入らない業者は外す。
3. **納期**: 急ぐなら国内（DMM.make）。急がないなら、JLC3DP と V3DPrint も選べる。
4. **総額**: 見積もりで比べる。JLC3DP と V3DPrint は、送料と関税・消費税を足した**届いた時点の総額**で比べる。
5. **試し刷り**: 3 点とも一度に頼まず、最初は安い素材で 1 点（SG2210P か ER605）だけ頼んで、実機で合うかを確かめる。SG2210P のモデルは実機の報告が見つからないので、購入後に合わせる。

## データの形式

一部のモデルは STL ではなく 3MF 形式で配布されている（STL は形状だけ、3MF は形状に加えて色や印刷設定などを持てる形式）。

| 業者 | 3MF | 備考 |
| --- | --- | --- |
| DMM.make | 対応（2017 年に対応を発表。現在の入稿条件は未確認） | 公式の対応形式の一覧は見つからなかった。見積もり画面で試す |
| JLC3DP | 見積もりページは STL、STP、STEP、OBJ、3MF を挙げる。ヘルプは 3MF をカラー印刷向けとし、STL を推奨 | 1 ファイルに 1 モデルだけ入れる。1 ファイル 100 MB まで、同時に 10 ファイルまで |
| アクセア | 対応（STL、3MF、OBJ） | |
| V3DPrint | 不明（問い合わせフォームでファイルを送る） | 事前に聞く |

- **迷ったら STL に変換して送る。** 形状だけを送るので、どの業者でも通りやすい。変換は、無料のスライサー（PrusaSlicer、Bambu Studio、OrcaSlicer など）で 3MF を開き、モデルを STL として書き出す。
- 3MF に複数のモデルや、スライサー用の設定（修飾子、複数のプレート）が入っている場合は、**1 部品ずつ STL に書き出す**。そのまま送ると、業者が複数の部品を 1 つと見なしたり、別の部品が混ざったりする。
- 書き出した STL は、スライサーで開き直して、向き、外形（幅約 250 mm）、部品の数を確認してから送る。
- 配布データが向き調整済みの場合は、書き出しても向きを変えない。

## 素材と造形方式の注意点

以下は一般的な目安で、各社の仕様は見積もり画面や素材ページで確認する。

### 素材

| 素材 | 特徴 | このラックでの注意 |
| --- | --- | --- |
| PLA | 刷りやすく安い。熱に弱い（約 60℃ 前後で柔らかくなる） | 作者は M70q 用で「使えるが、熱で柔らかくなる」と書いている。夏場や閉じた棚は避ける。実際には PLA で問題なく使っている人もいる（コメント欄）が、長期は不明 |
| PETG | 熱と衝撃に強く、PLA より変形しにくい。糸引きが出やすい | 作者の推奨。ベッドへの密着はよいが、糸引きの後処理が要ることがある |
| ABS / ASA | 耐熱が高く丈夫。反りやすい（大きな板は特に）。ASA は耐候性が高い | 作者の推奨。幅 250 mm の板は反りやすいので、頼む前に業者の実績や、反り対策の有無を問い合わせる。 |
| PA12（MJF ナイロン） | 粉末を焼き固める方式。方向による強度差が小さく、粘りがある。表面は粉っぽくざらつく。色は灰色（染色できる） | 強度と耐熱は高いが、素材費が高い。穴の寸法は収縮で少しずれる（±0.3 mm 程度を見込む） |
| 光造形レジン | 表面がなめらか。もろく、紫外線で劣化する | 本体の荷重がかかるマウントには**向かない** |

### 造形方式

- **FDM**: 積層の方向に弱い。本体の重さがかかる板は、層が剥がれる向きに力がかからないように刷る。作者は前面を下にして刷る向きを推奨している（配布データは向き調整済み）。サポートは不要。業者に頼むときも、この向きで刷るよう指定できるか確認する。
- **MJF / SLS（粉末焼結）**: サポート不要で、強度の方向差が小さい。後処理（染色、研磨）を頼める業者もある。見た目は粉っぽい。
- **光造形**: このラックの用途には使わない。

### 共通の注意

- **公差**: 業者の公差は FDM、MJF とも ±0.3 mm 程度。ネジ穴とキーストーンの口は、作者がきつめに作っている。きついときは手でバリを取る。穴を後から広げられるよう、最初は 1 点だけ試す。
- **ネジ**: ラックへの固定は M5 か M6（ラックの規格による）。ケージナットが要ることもある。購入前に、使うラックの穴のサイズを確認する。
- **機器ごとの確認**: ER605 は V2 を買う予定。SG2210P は版数で外形が変わらないか確認する。M70q は実機を測る。
- **データの扱い**: 業者に送るのは自分用の印刷なので、CC BY-NC でも問題ない（[README](README.md#ライセンスとこのリポジトリに載せてよいか)）。他人のために頼む、売る、などは BY-NC では禁止。
- **海外発注の税**: 海外から届く荷物には、関税と消費税（通関時）がかかることがある。比較記事は、これらを扱っていない。注文前に、業者の送料表示（DDP＝関税込みで届くか）と運送会社の条件を確認する。
