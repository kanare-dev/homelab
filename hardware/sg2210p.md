### ソフトウェアの機能

| 分類 | 内容 |
| --- | --- |
| Omada SDN | Omada のハードウェアコントローラーとソフトウェアコントローラーに対応。自動検出、一括設定、一括ファームウェア更新、状態の監視、再起動のスケジュール。ゼロタッチプロビジョニングは、クラウドベースのコントローラーだけ |
| VLAN | 最大 4K の VLAN グループ、802.1Q のタグ VLAN、MAC VLAN（12 エントリ）、プロトコル VLAN（802.1v）、GVRP、音声 VLAN |
| ACL | 最大 230 エントリ。MAC ACL、IP ACL、IPv6 ACL、時間指定。許可・拒否のほか、ミラー、レート制限、リダイレクト、QoS の書き換え。ポートまたは VLAN に紐づけ |
| ミラーリング | ポートミラーリング、CPU ミラーリング。1 対 1、多対 1、フローベース。入力・出力・両方向 |
| レイヤー 2 | リンクアグリゲーション（静的、LACP。最大 8 グループ、1 グループ 8 ポート）、STP / RSTP / MSTP、ループ検出、LLDP、802.3x フロー制御 |
| マルチキャスト | IGMP スヌーピング（v1/v2/v3）、MLD スヌーピング、MVR、マルチキャストフィルタ |
| QoS | 802.1p CoS / DSCP、8 つの優先キュー、SP / WRR、レート制限、ストームコントロール |
| セキュリティ | 802.1X（ゲスト VLAN を含む）、ポートセキュリティ、DHCP スヌーピング、DAI、IP/IPv6-MAC バインディング、IP ソースガード、DoS 防御、ポートアイソレーション、HTTPS、SSH |
| レイヤー 3 | スタティックルーティング、DHCP サーバー、DHCP リレー、スタティック ARP |
| IPv6 | デュアルスタック、IPv6 のスタティックルーティングと ACL、ND など |
| 管理 | Web、CLI（telnet、SSH）、SNMP v1/v2c/v3、RMON、SNTP、システムログ、Dual Image / Dual Configuration、DDM、EEE |

データシートの注記: 機能の一部は、最新のソフトウェアに更新したあとに使える。

## このホームラボでの使い方との対応

| 論点 | データシートから分かること |
| --- | --- |
| trunk / access / native VLAN | 802.1Q のタグ VLAN に対応。[移行計画](../docs/operations/roadmap/10-er605-sg2210p-migration-plan.md)のポート割り当て（p1 trunk、p2 trunk（全 VLAN をタグ付き。native は未使用の VLAN1）、p3 access）は実現できる |
| 通信の複製（ntopng） | 多対 1、入力・出力・両方向のポートミラーリングに対応。[ネットワーク通信の収集・可視化](../docs/operations/roadmap/06-network-traffic-analysis.md)の Phase 2 で使える |
| VLAN 間の通信の制限 | 計画は ER605 のゲートウェイ ACL に頼る。ER605 で足りなければ、SG2210P の ACL（230 エントリ）を使う道がある（[VLAN 設計](../docs/architecture/08-vlan-design.md)の未決事項） |
| 仕事用 PC を別の VLAN に分ける案 | MAC VLAN（12 エントリ）に対応。ドック経由で MAC が安定するかは、実機で確認する |
| AP への給電（段階 4） | PoE+ は 8 ポート、1 ポート 30 W まで、合計 61 W。AP の消費電力の合計が 61 W に収まる台数にする |
| 設置場所 | ファンレスで、動作温度は 40 ℃ まで。ラックや棚に入れるときは、熱がこもらないようにする。ラックマウントの金具は付属しない（[10 インチラック](rack-10inch/README.md)の 3D プリントの金具を使う案） |
| ルーター機能・DHCP サーバー | 本機にもあるが使わない。ゲートウェイと DHCP は ER605 に一本化する |
| IPv6 | 本機は対応するが、家では IPv6 を無効にする方針（[ADR-0017](../docs/adr/0017-ipv6-disabled.md)） |
