# TP-Link ER605 V2

Omada のギガビット VPN ルーター（ゲートウェイ）。移行では、Buffalo に替わって家の入口のルーターになり、VLAN のゲートウェイ・DHCP・ACL を担う。公式の資料へのリンクと、データシートの仕様をまとめる。移行の手順は[ER605・SG2210P の移行計画](../docs/operations/roadmap/10-er605-sg2210p-migration-plan.md)、VLAN の設計は[VLAN 設計](../docs/architecture/08-vlan-design.md)、ルーターを選んだ判断は[ADR-0009](../docs/adr/0009-router-er605-first.md)にある。

> [!NOTE]
> 確認日は 2026-11-03。購入したのは **ER605(UN) V2.30**（運用者が本体で確認）。仕様は、公式サイトで最新のデータシート（2025-09-02 掲載、ハードウェアは V2.2）による。**V2.30 のデータシートは、公式サイトに見つけられなかった**。同じ V2 系なので、数値は近いと見るが、V2.30 での差は未確認。数値は原文のまま載せている。

## このホームラボでの使い方との対応

| 論点 | データシートから分かること |
| --- | --- |
| ポート数 | WAN × 1、LAN/WAN × 2、LAN × 2。WAN を 1 つ使っても、LAN は 3 つ以上確保できる（[VLAN 設計](../docs/architecture/08-vlan-design.md)）。移行計画では、LAN の 1 本を SG2210P の p1（trunk）に使う。段階 1 の間は、Proxmox と Buffalo も ER605 の LAN に繋ぐ |
| 回線の速度 | NAT のスループットが約 940 Mbps で、家の回線（下り約 530 Mbps、上り約 600 Mbps）に足りる（[ADR-0009](../docs/adr/0009-router-er605-first.md)） |
| mDNS の中継 | mDNS リピーターに対応。Trusted ↔ IoT の中継に使う。必要なコントローラーの版（ゲートウェイの mDNS は v5.6 以降）は[VLAN 設計](../docs/architecture/08-vlan-design.md)の未決事項にある |
| VLAN 間の通信の制限 | ステートフル ACL と IP ベースのアクセス制御に対応。コントローラーモードの Gateway ACL で、LAN → LAN を制限できるかは、実機で確認する（[VLAN 設計](../docs/architecture/08-vlan-design.md)の未決事項） |
| IPv6 | 本機は対応するが、家では IPv6 を無効にする方針（[ADR-0017](../docs/adr/0017-ipv6-disabled.md)） |
| VPN | Tailscale を使うので、本機の VPN 機能は使わない。参考までに、WireGuard は 82.62 Mbps |
| ポートミラーリング | 管理機能にポートミラーリングの記載があるが、使える範囲は未確認。通信の取得は、SG2210P のミラーリングを第一候補にしている（[ネットワーク通信の収集・可視化](../docs/operations/roadmap/06-network-traffic-analysis.md)） |
| スタンドアロンだけの機能 | CLI、NTP 同期、RIP / OSPF、GRE、LDAP、DHCPv6 PD サーバー。コントローラーに採用したあとは使えない。NTP は、コントローラー側の設定で行う |
| 設置 | ファンレス。動作温度は 40 ℃ まで。寸法 158 × 101 × 25 mm で、10 インチラックに収まる（[10 インチラック](rack-10inch/README.md)）。電源は外付けアダプター |
